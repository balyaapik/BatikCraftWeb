## How Work Is Credited

Every change reaches `main` through a commit that describes what changed and why. The
commit history is the authoritative record of who contributed what; this file names the
people behind those commits.

## AI Assistance

Parts of this codebase were written with the help of AI coding assistants. The team's
policy for that work:

- AI-assisted output is treated as a draft, never as a finished change.
- A team member reviews the diff, runs the test suite, and accepts responsibility for
  the result before it is merged.
- Behavioural changes ship with regression tests that fail without the change.
- Performance claims in the documentation are backed by measurements recorded in the
  relevant commit message.

Earlier assisted-development notes were removed when the documentation was rewritten in
English. They remain available in the git history.
